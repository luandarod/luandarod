## 👩‍💻 Sobre mim

Venho da engenharia biomédica e da gestão hospitalar — passei por farmácia clínica, operações de saúde pública (EBSERH) e projetos de marketing e mídia em saúde antes de migrar para dados. Essa bagagem molda como eu trabalho hoje: gosto de pegar sistemas complexos (de saúde, mercado ou operação) e transformá-los em dados legíveis, com comunicação voltada para decisão, não só para o dashboard bonito.

Hoje conecto **SQL, BI, cloud analytics e machine learning** em produtos que alguém de fora da área de dados consegue entender e usar.

- 🩺 Fundo clínico e hospitalar aplicado à análise de dados de saúde
- 📊 BI orientado a decisão, não a vaidade de métricas
- 🌍 Aberta a trabalho remoto e realocação
